# Ultimate Menu for Nenyoo

Ultimate Menu runs in Nenyoo on GTA V Legacy and Enhanced with the same menu structure and controls as the YimMenu edition.

## Install

1. Copy this folder to `%LOCALAPPDATA%\Nenyoo\Plus\Scripts\User\UltimateMenu\`.
2. Keep `Ultimate_Menu.lua` and the `lib` folder together.
3. In Nenyoo, open **Scripts** and select `Ultimate_Menu.lua`.

Online features become available after joining GTA Online.

## Supported builds

- GTA V Legacy 3889
- GTA V Enhanced 1158.13

The correct offset catalog is selected automatically. Build-specific globals and locals are stored in:

- `lib/game_offsets_legacy.offsets`
- `lib/game_offsets_enhanced.offsets`
