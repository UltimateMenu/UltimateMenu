# Ultimate Menu for Yimmenu

## Install

**Legacy**

1. Copy the `Ultimate_Menu_Legacy.lua` file to `C:\Users\YOURUSERNAME\AppData\Roaming\YimMenu\scripts`.

2. Go to `Settings` in Yimmenu.

3. Select the Script and Load it.

**Enhanced** 

1. Copy the `Ultimate_Menu_Enhanced.lua` file to `C:\Users\YOURUSERNAME\AppData\Roaming\YimMenuV2\scripts`.

2. Go to `Settings` in YimmenuV2.

3. Select the Script and Load it.

Online features become available after joining GTA Online.

## Supported builds

- GTA V Legacy 3889
- GTA V Enhanced 1158.13
